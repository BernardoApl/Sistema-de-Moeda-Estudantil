# Sistema de Moeda Estudantil

Projeto acadêmico em Python e Flask para reconhecimento do mérito estudantil. Professores distribuem moedas, alunos consultam extratos e resgatam vantagens, e empresas parceiras gerenciam ofertas e conferem cupons.

## Começar

O [guia de execução](<Entrega Sprint 3/README.md>) contém instalação, contas fictícias, comandos administrativos e testes. A aplicação utiliza SQLite localmente; a configuração para nuvem utiliza PostgreSQL. O envio efetivo de e-mails exige SMTP configurado e execução do comando da caixa de saída.
